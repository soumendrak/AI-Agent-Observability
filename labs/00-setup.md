# Lab 0: Setup

## Goal

A working setup before the workshop, proved by a READY code.

## When

At home, after the setup email.

## Steps

1. Follow the setup in the [repo README](../README.md#setup). Each step checks first and installs only what is missing, so you can run it again on a laptop that is already set up.
2. Run `uv run ws doctor` and wait for `READY-` followed by four characters.
3. Open the printed hello-trace link and check you can see the trace.
4. Submit your READY code, and your partner's name if you're pairing, on the form from the setup email.

## Checkpoint

You have a READY code, and the hello trace opens in your Langfuse project.

## If you're stuck

Find the message in [troubleshooting](../docs/troubleshooting.md). Still stuck? Post the exact message in the workshop chat, but never your secret key. No laptop you can install on? Pair with someone who has a working setup.
